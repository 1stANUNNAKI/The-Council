## ⚡ Install

```bash
npx majlis-council --all          # every platform
npx majlis-council --claude       # single platform (--codex --opencode --gemini --universal)
npx majlis-council --scaffold .   # project rule-pointers (Cursor/Windsurf/Copilot/...)
```

Windows source installer: `powershell -File install_system.ps1`

## 🕹️ Lifecycle

| Command | Gate enforced |
|---|---|
| `/majlis:start` | guided init → `.majlis/PROJECT.md + ROADMAP.md + STATE.md` |
| `/majlis:plan n` | tasks without runnable `verify:` are **rejected** |
| `/majlis:build` | parallel waves, forbidden-glob respect, atomic commits |
| `/majlis:review` | anti-sycophancy panel, max 3 cycles, BLOCKER bounces back |
| `/majlis:security` | TruffleHog → Nuclei → OWASP ZAP → **SECURITY PASS mandatory** |
| `/majlis:status` | dashboard + exact next action |
