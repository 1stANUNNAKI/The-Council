## 1. المكتبات الأساسية
تستخدم مع أي مشروع (HTML/JS/Vue/React).

| المكتبة | الوصف | الرابط |
| :--- | :--- | :--- |
| **GSAP** | الأقوى عالمياً للحركات المعقدة وربط الحركة بالتمرير. | [GitHub](https://github.com/greensock/GSAP) |
| **Anime.js** | محرك حركي خفيف ومرن جداً للـ CSS و SVG. | [GitHub](https://github.com/juliangarnier/anime) |
| **Sal.js** | مكتبة فائقة الأداء تعتمد على Intersection Observer. | [GitHub](https://github.com/mciastek/sal) |
| **ScrollReveal** | الأبسط لعمل تأثيرات ظهور العناصر عند التمرير. | [GitHub](https://github.com/jlmakes/scrollreveal) |

## 2. مكتبات React & Next.js
مكونات جاهزة وتكامل عميق مع React.

| المكتبة | الوصف | الرابط |
| :--- | :--- | :--- |
| **Framer Motion** | المعيار الأساسي للأنيميشن في React. | [GitHub](https://github.com/framer/motion) |
| **Aceternity UI** | مكونات "بريميوم" جاهزة (انسخ والصق). | [Website](https://ui.aceternity.com/) |
| **Magic UI** | مكونات بصرية مذهلة وحركات حديثة. | [Website](https://magicui.design/) |

## 3. أدوات التمرير الناعم (Smooth Scroll)
لإعطاء الموقع إحساس الفخامة (Premium Feel).

*   **[Lenis Scroll](https://github.com/darkroomengineering/lenis):** المكتبة المفضلة حالياً للمحترفين، تضمن تمرير سلس جداً دون التأثير على أداء المتصفح.

## 4. تأثيرات البارالاكس (Parallax)
*   **[Rellax](https://github.com/dixonandmoe/rellax):** لعمل طبقات تتحرك بسرعات مختلفة عند التمرير.

## 5. قوالب ومكونات التصميم المتجاوب (Responsive Design)
أفضل الموارد لضمان توافق الموقع مع جميع الأجهزة.

| المورد | الوصف | الرابط |
| :--- | :--- | :--- |
| **Cruip Open Templates** | قوالب هبوط احترافية جداً لـ React و Tailwind. | [GitHub](https://github.com/cruip/open-react-template) |
| **AstroWind** | قالب فائق السرعة والأداء مبني بـ Astro. | [GitHub](https://github.com/onwidget/astrowind) |
| **HyperUI** | مجموعة مكونات Tailwind جاهزة للنسخ. | [GitHub](https://github.com/markmead/hyperui) |
| **Flowbite** | مكتبة مكونات UI شاملة ومتوافقة. | [GitHub](https://github.com/themesberg/flowbite) |
| **Shadcn/ui** | نظام تصميم حديث يمنحك تحكماً كاملاً. | [GitHub](https://github.com/shadcn-ui/ui) |

## 🛠️ كيف تبدأ؟
للحصول على أفضل النتائج، ننصح بالدمج بين:
1. **Lenis** للتمرير الناعم.
2. **GSAP (ScrollTrigger)** للحركات المخصصة.
3. **Framer Motion** إذا كنت تستخدم React.

تم إعداد هذا الملف بواسطة **المجلس (Majlis)**.
