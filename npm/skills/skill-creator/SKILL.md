# 🛠️ مهارة صانع ومولد المهارات والوكلاء (Skill & Agent Creator)

## 📋 Agent Metadata & Team Identity
- **اسم المهارة:** مهارة صانع المهارات والوكلاء الجدد (Skill Creator)
- **اسم الوكيل:** 🧰 مبتكر (Agent 20) بالتعاون مع 🐣 مُجَنِّد / نَسَّاج (Agent 02)
- **الإيموجي:** 🛠️🏗️
- **التسلسل الفني في الفريق:** Agent 20 / Agent 02
- **الموقع في خط الإنتاج:** هندسة وصناعة أدوات ومهارات الوكلاء المتخصصة (Agent & Skill Scaffolding Engine)
- **سلسلة العمل:**
  1. تحليل متطلبات المهارة أو الوكيل الجديد المطلوب.
  2. التثبت من وجود حلول مفتوحة المصدر أو مستودعات جاهزة على GitHub.
  3. إنشاء المجلد المخصص داخل `.agents/skills/<skill-name>`.
  4. صياغة ملف `SKILL.md` شاملاً الترويسة القياسية (YAML Frontmatter)، الهيكل التنفيذي، الاعتماديات، السكربت التأسيسي، والقواعد الصارمة.
  5. ربط المهارة بالوكلاء المعنيين وتحديث التوثيق.

---

## 🛠️ Prerequisites (الاعتماديات والبيئة)
1. **npx / Node.js**: تشغيل حزمة `skills` عبر `npx skills add https://github.com/anthropics/skills --skill skill-creator`.
2. **Python 3.10+ / Git**: لاستنساخ الحزم وإنشاء السكربتات التأسيسية.

---

## 🔍 Overview (نظرة عامة وآلية العمل)
تُمكن هذه المهارة النظام من التوسع الذاتي عبر توليد وتصنيع مهارات جديدة للوكلاء فور مواجهة مهام تخصصية تتطلب أدوات جديدة.

**Do NOT use when:**
- المهارة موجودة ومثبتة بالفعل في النظام.
- المهام البسيطة التي لا تستدعي إنشاء هيكل مهارة مستقل.

---

## ⚙️ Core Rules (القواعد الصارمة)
1. **[الالتزام بالهيكل القياسي]:** يجب أن يحتوى ملف `SKILL.md` على الترويسة، البيانات الوصفية، الاعتماديات، السكربت التأسيسي، القواعد، وسلسلة المخرجات.
2. **[أولوية المكتبات والمشاريع الجاهزة]:** الاعتماد على المستودعات الموثوقة على GitHub بدلاً من إعادة اختراع العجلة.
3. **[عدم كسر البيئة - Zero Breaking]:** اختبار المهارة في بيئة معزولة وتأكيد سلامة الملفات المنشأة.

## 🚀 Quick Start (نموذج توليد مهارة جديدة)

```bash
npx skills add https://github.com/anthropics/skills --skill skill-creator
```
