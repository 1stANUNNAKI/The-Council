# 🔍 مهارة باحث واستكشاف المهارات (Find Skills Engine)

## 📋 Agent Metadata & Team Identity
- **اسم المهارة:** مهارة البحث واكتشاف المهارات (Find Skills Engine)
- **اسم الوكيل:** 🧰 مبتكر (Agent 20) بالتعاون مع 🔍 راصد (Agent 03) و 🎼 مايسترو هادي (Agent 01)
- **الإيموجي:** 🔍🌐
- **التسلسل الفني في الفريق:** Agent 20 / Agent 03 / Agent 01
- **الموقع في خط الإنتاج:** الاستكشاف والمسح التقني للأدوات (Technical Discovery & Skill Finder)
- **سلسلة العمل:**
  1. استقبال الاستعلام البحثي أو الهدف الوظيفي المطلوب.
  2. المسح والاستكشاف في مكتبات المهارات العالمية ومستودعات GitHub.
  3. اختيار المهارة الأكثر ملاءمة وأماناً وكفاءة.
  4. تنزيل المهارة وتضمينها ضمن مجلد مهارات النظام `.agents/skills/`.
  5. إبلاغ الوكيل المختص وتحديث مصفوفة أدواته.

---

## 🛠️ Prerequisites (الاعتماديات والبيئة)
1. **npx / Node.js**: تشغيل حزمة `skills` عبر `npx skills add https://github.com/vercel-labs/skills --skill find-skills`.
2. **اتصال بالإنترنت / GitHub API**: للمسح والاستكشاف التقني.

---

## 🔍 Overview (نظرة عامة وآلية العمل)
تُستخدم هذه المهارة لإجراء فحص وتنقيب شامليْن (360-degree skill discovery) للوصول إلى أفضل المهارات المتاحة وتغذية وكلاء المجلس بالأدوات الجاهزة فائقة الأداء.

**Do NOT use when:**
- المهارات متوفرة ومثبتة محلية ضمن النظام.
- الطلب لا يحتاج أدوات خارج نطاق بيئة العمل الحالية.

---

## ⚙️ Core Rules (القواعد الصارمة)
1. **[الفحص الأمني المسبق]:** التحقق من أمان المهارات المكتشفة وعدم حاويتها على أية ثغرات.
2. **[التوافق التام]:** تأكيد توافق المهارة المستكشفة مع بيئة عمل المجلس.
3. **[التوثيق المكتمل]:** تسجيل المهارات المكتشفة في `وثائق العمل/`.

---

## 🚀 Quick Start (بدء سريع)

```bash
npx skills add https://github.com/vercel-labs/skills --skill find-skills
```

---

## 📊 Interpreting Output
- **تحديد المهارة وتثبيتها:** يتم حفظ المهارة وتثبيتها في `.agents/skills/<discovered_skill>`.
