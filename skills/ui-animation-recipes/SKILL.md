# 🪄 مهارة حركيات الواجهات والوصفات المعيارية · UI Animation Recipes
### (مبنية ومطوّرة عن فلسفة ومعايير إميل كوفالسكي العالمية للأنيميشن)

> **المسؤول في المجلس:** 🎨 إلهام (Agent 11) + 🖌️ رَفَل (Agent 12) + 💻 فارس (Agent 15)  
> **الهدف الجوهري:** تحويل طلبات الحركة في الواجهات من حركات عشوائية وبطيئة ("سلوب") إلى حركات احترافية فورية ومريحة للعين، تحترم أداء المتصفح (GPU) وتقلل الحمل الإدراكي للمستخدم.

---

## 1. 🛑 بوابة القرار الإلزامية: هل يحتاج هذا العنصر إلى حركة أصلاً؟

| معدل الاستخدام اليومي | القرار الحاسم | التفسير الفني |
| :--- | :--- | :--- |
| **100+ مرة يومياً** (اختصارات لوحة المفاتيح، لوحة الأوامر Command Palette، أزرار البحث المتكررة) | **ممنوع الحركة نهائياً (Zero Animation)** | الحركة هنا تصبح عائقاً وإرهاقاً بصرياً. التبديل الفوري هو الأصح (مثل Raycast). |
| **عشرات المرات يومياً** (أزرار القوائم، التنقل بين عناصر الجداول، تأثيرات Hover) | **حركة فائقة السرعة وخفية جداً (<150ms)** أو لا شيء | مجرد لمسة تفاعلية تؤكد الاستجابة دون تأخير الإجراء. |
| **بضع مرات يومياً / استخدام عادي** (النوافذ المنبثقة Modals، القوائم المنسدلة Dropdowns، الأدراج Drawers، التوست Toasts) | **حركة معيارية مضبوطة (150ms - 250ms)** | تمنح إحساساً بالفخامة والاتساق الفراغي. |
| **نادر / لأول مرة** (شاشات الترحيب Onboarding، إشعارات النجاح الكبرى، احتفالات إتمام الدفع) | **ميزانية المتعة والبهجة (Delight Budget)** | هنا فقط يُسمح بالحركات الاستعراضية الأطول. |

> **قاعدة ذهبية:** إجراءات لوحة المفاتيح لا يُطبّق عليها أي أنيميشن إطلاقاً.

## 2. 🎯 تحديد الغاية الوظيفية للحركة (The Named Purpose)

قبل كتابة أي سطر CSS أو JS، يجب تحديد هدف الحركة في كلمة واحدة من الكلمات التالية:
1. **التغذية الراجعة (Feedback):** تأكيد أن النظام سمع نقرة المستخدم (مثل ضغط الأزرار `scale(0.97)`).
2. **الاتساق الفراغي (Spatial Consistency):** إظهار من أين أتى العنصر وإلى أين يذهب (القوائم تخرج من زرها عبر `transform-origin`).
3. **بيان الحالة (State Indication):** توضيح تبدل حالة العنصر بوضوح (مثل التبديل بين التبويبات).
4. **منع القفزات المزعجة (Preventing Jarring Teleportation):** تجسير التغيير بسلاسة بدلاً من ظهور فجائي مشوش.
5. **الشرح والإيضاح (Explanation):** شرح آلية عمل معينة (لصفحات التسويق والترحيب فقط).

## 3. 📐 المنحنيات الكنسية المعيارية للتباطؤ (Canonical Easing Tokens)

يُحظر منعاً باتاً استخدام المنحنيات الافتراضية للـ CSS (مثل `ease-in` المبتذل). المنحنيات المعتمدة قطعيّاً في النظام هي:

```css
:root {
  /* المنحنى القياسي لكافة عناصر الواجهات عند الدخول والخروج */
  --ease-out: cubic-bezier(0.23, 1, 0.32, 1);

  /* منحنى الحركات المستمرة والتحول الفراغي داخل الشاشة */
  --ease-in-out: cubic-bezier(0.77, 0, 0.175, 1);

  /* المنحنى المعتمد للأدراج وشاشات السحب السفلية الشبيهة بنظام iOS */
  --ease-drawer: cubic-bezier(0.32, 0.72, 0, 1);
}
```

### متى تستخدم كل منحنى؟
- **الدخول والخروج (Entering/Exiting):** دائماً `--ease-out`. يُحظر `ease-in` لأنه يبدأ بطيئاً فيعطي إحساساً بالبطء والتأخر.
- **التحرك بين المواضع (Morphing/Moving):** استخدم `--ease-in-out`.
- **التبديل اللوني وتأثيرات Hover البسيطة:** استخدم `ease`.
- **أشرطة التقدم والمؤشرات الزمنية:** استخدم `linear`.

## 4. ⚡ الميزانية الزمنية الصارمة (Duration Budget)

- **نقرات الأزرار والتفاعل الفوري:** 100ms – 160ms.
- **التولتيب (Tooltips) والقوائم المصغرة:** 125ms – 200ms.
- **القوائم المنسدلة والـ Select:** 150ms – 250ms.
- **النوافذ المنبثقة (Modals) والأدراج (Drawers):** 200ms – 300ms (حد أقصى 500ms للأدراج الطويلة مع السحب).
- **قاعدة الحظر:** أي حركة واجهة تتجاوز 300ms دون مبرر فيزيائي تعتبر عيباً برمجياً (Bug).

## 5. 🚫 قائمة المحظورات القطعية (Never Ship Checklist)

| الممارسة الممنوعة (Never) | البديل المعياري المعتمد (Instead) |
| :--- | :--- |
| `transition: all` | حدد الخصائص الصريحة فقط: `transition: transform 200ms var(--ease-out), opacity 200ms var(--ease-out)` |
| الدخول عبر `transform: scale(0)` | ابدأ من `scale(0.95)` مع `opacity: 0`؛ لا شيء في الطبيعة يخرج من نقطة الصفر. |
| استخدام `ease-in` على عناصر الواجهة | استخدم `--ease-out` أو المنحنى الكنسي `cubic-bezier(0.23, 1, 0.32, 1)`. |
| تحريك `width` أو `height` أو `margin` أو `top/left` | حرك `transform` و `opacity` فقط لتسريع المعالجة بكرت الشاشة (GPU). |
| `transform-origin: center` في القوائم والـ Popovers | حدد نقطة الأصل عند زر التفعيل: `transform-origin: var(--transform-origin)` (النوافذ المركزية Modals مستثناة). |
| استخدام Keyframes على التوست والإشعارات المتكررة | استخدم CSS Transitions لتبدأ الحركة من موضعها اللحظي عند مقاطعتها. |
| إهمال دعم تقليل الحركة (Reduced Motion) | وفّر بديلاً لطيفاً يعتمد التلاشي اللوني (Fade) دون حركات إزاحة عنيفة. |
| تفعيل الـ Hover على شاشات اللمس | غلّف تأثيرات الـ Hover داخل `@media (hover: hover) and (pointer: fine)`. |
| ظهور جميع عناصر القائمة دفعة واحدة | استخدم التتالي الزمني الخفيف (Stagger) بمقدار 30ms إلى 50ms بين كل عنصر. |
